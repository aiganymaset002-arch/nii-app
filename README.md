# НИИ — приложение для iPhone и iPad

Приложение НИИ Инклюзивного Инжиниринга для App Store. Это **отдельное приложение**:
оно никак не связано с сайтом журнала, сервер и root ему не нужны.
Данные хранятся в облаке Supabase — в отдельном проекте НИИ (`kvqjqynvcmdxkesjvzdj`).

## Что умеет

Три вида входа:

| Кто | Что видит |
|---|---|
| **Организатор** (вы) | Задачи на сегодня, план «90 дней» (Точка А → 12 недель → Точка Б), ключевые показатели, люди и роли, создание конференций с Zoom и описанием, курсов и уроков, программ, новостей, мерча; приём заявок и заказов |
| **Команда НИИ** | Свои задачи, онлайн-лаборатория и встречи (может создавать их сама), курсы |
| **Участник** | Курсы (видеоуроки, прогресс, сертификат), конференции и семинары с записью и Zoom, онлайн-лаборатория, заявки на программы, новости, мерч |

**Платно — NII Pro, $39.99 в месяц** (подписка через App Store): PRO-курсы, закрытые конференции и онлайн-лаборатория.
Бесплатно Pro получают: команда, организатор и семья (семейный пароль — тот же, что на сайте).
Мерч — физический товар, оплачивается переводом на Kaspi +7 771 473 18 52.

## Как запустить — 3 шага

### 1. База данных (один раз, 2 минуты)
1. Откройте [supabase.com](https://supabase.com) → проект KKSU → **SQL Editor** → **New query**.
2. Скопируйте весь файл [`backend/schema.sql`](backend/schema.sql), вставьте и нажмите **Run**.
3. Внизу появятся два кода — **сохраните их**:
   - `admin_code` (ADMIN-…) — для вашего входа как организатор;
   - `team_code` (TEAM-…) — раздайте сотрудникам.

Файл можно запускать повторно — данные не пропадут.

### 2. Открыть в Xcode (нужен Mac)
1. Скачайте проект: зелёная кнопка **Code → Download ZIP** и распакуйте.
2. Откройте `NII.xcodeproj` в Xcode 16 или новее.
3. Слева нажмите на **NII** → вкладка **Signing & Capabilities** → **Team** — выберите свой Apple Developer аккаунт.
   Если `kz.nii.app` занят — поменяйте Bundle Identifier, например на `kz.nii.app2`.
4. Нажмите ▶️ — приложение запустится на симуляторе или iPhone. Покупка Pro в тесте работает через файл `NII.storekit` (деньги не списываются).

### 3. Выпустить в App Store
1. [App Store Connect](https://appstoreconnect.apple.com) → **Приложения → +** → новое приложение с тем же Bundle ID.
2. Внутри приложения → **Монетизация → Подписки** → группа «NII Pro» → подписка с кодом
   **`kz.nii.app.pro.monthly`**, срок 1 месяц, цена $39.99.
3. В Xcode: **Product → Archive → Distribute App → App Store Connect**.
4. Заполните описание, скриншоты, ссылку на политику конфиденциальности:
   `https://github.com/aiganymaset002-arch/nii-app/blob/main/PRIVACY.md` → **Отправить на проверку**.

## Первый вход
- **Вы:** «Регистрация» → роль «Организатор» → вставьте `admin_code`.
- **Сотрудник:** роль «Команда НИИ» → `team_code`.
- **Семья:** «У меня есть семейный пароль» → семейный пароль.
- Код можно ввести и позже: **Профиль → Коды доступа**.

## Устройство проекта
```
NII/Core      — связь с облаком, модели, план 90 дней, подписка
NII/Views     — экраны
backend/      — schema.sql: таблицы и правила доступа (проверяются базой, не приложением)
NII.storekit  — тестовая подписка для Xcode
```
Сборка проверяется автоматически на GitHub (вкладка **Actions**).

Ключ в `NII/Core/Config.swift` — публичный (publishable), так и должно быть.
Секретный ключ `service_role` в приложение **никогда** не вставляйте.
