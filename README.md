# NII App

Приложение НИИ Инклюзивного Инжиниринга: курсы, конференции, онлайн-лаборатория,
программы, новости, мерч, подписка NII Pro и управление задачами НИИ.

Приложение полностью отдельное от сайта журнала: своя папка, своя база данных, свой адрес.

Работает в браузере и ставится на телефон иконкой (PWA).

## Три вида входа

| Роль | Что может |
|------|-----------|
| **Организатор (админ)** | панель с задачами на день и ключевыми результатами, план «90 дней», задачи команде, конференции и встречи с Zoom, курсы с уроками, программы и заявки, новости, мерч, подтверждение оплат, люди и роли |
| **Команда НИИ** | свои задачи, создание сессий онлайн-лаборатории и встреч, всё, что видит участник |
| **Участник** | новости, курсы и сертификаты, запись на конференции (ссылка Zoom, календарь), онлайн-лаборатория, заявки в программы, мерч, подписка Pro, переход на сайт журнала для публикации статьи |

Регистрация организатора и команды — по кодам из `config.local.php`.
Семейный пароль даёт бесплатный Pro, курсы и мероприятия (мерч остаётся платным).

## Что платное

- **NII Pro — $40 / месяц**: все Pro-курсы, онлайн-лаборатория и консультации, закрытые семинары,
  сертификаты, приоритет в программах.
- Отдельно: платные курсы, платные конференции, мерч.

Оплата — переводом на Kaspi с загрузкой чека; организатор подтверждает в «Оплатах», доступ открывается сам.

## Установка на сервер

На сервере уже должны быть nginx, PHP 8.3 и MySQL (они есть, если сервер настраивался для другого сайта).

```bash
git clone https://github.com/aiganymaset002-arch/nii-app.git /var/www/nii-app
bash /var/www/nii-app/install.sh
```

Скрипт сам создаёт отдельную базу `nii_app`, пароль к ней, коды регистрации и отдельный
сайт в nginx. Приложение откроется по адресу `http://<IP сервера>:8080`,
а после DNS-записи `A app → <IP сервера>` — по адресу `http://app.nii-arai-publishhouse.kz`.
